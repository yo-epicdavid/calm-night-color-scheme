# Samples

Screenshot fodder for the README and marketplace listings. Each file is
deliberately token-rich — comments, strings, numbers, types, keywords,
functions, decorators, and markup — so a single screenful shows off the
whole palette.

Open each in the matching editor and capture **both** variants (`Calm Night`
and `Calm Night Minimal`) side by side:

| File | Good for |
|------|----------|
| `sample.ts`, `sample.tsx` | WebStorm, VS Code |
| `sample.php` | PhpStorm |
| `sample.sql` | DataGrip |
| `sample.py`, `sample.css`, `sample.json`, `sample.md` | general / VS Code / Neovim |

Tip: hide the minimap and set a comfortable font size before capturing, and
grab the same file in both variants so the comparison is apples-to-apples.
